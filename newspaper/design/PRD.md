# 报纸 Agent App · PRD

> 初稿站位文档。只定方向、界面大概的样子和实现的大致路径，细节等动手时再补。

## 这是什么

报纸是一个新闻阅读器 Agent App。它自己不采集信息：Agent 配合采集类 skill 把新闻总结成短文，通过 MCP 工具逐条写入；用户打开面板读一份报纸样式的日报。App 不预设主题，挂什么采集 skill，它就是什么报。

### 其余视图

- 空状态：当期没有新闻时显示尚未投递的引导，指引用户去对话里叫 Agent 采集
- 往期：二级列表按期归档，显示日期、期号、条数、读完与否，点击进入该期头版

## 大概怎么做

数据流一条线：

```
skill 采集 → Agent 总结 → add_news 写入 → SQLite → WebSocket 推送 → 界面刷新
```

- 工具面三个：add_news 写入一条，query_news 查当期状态，clear_edition 清空重投。写入当场返回，第一版零 notification，阅读行为不回流 Agent
- 数据：SQLite。一天一期，跨天首次写入自动开新期；一条新闻含标题、一到两段正文、来源、原文链接、版面 tag；报名首次写入指定后沿用
- 技术：后端 Python 加 uv 双通道，前端 React 加 Vite；桌面与手机同版，手机压成单栏

## 大概什么样子

报纸质感是硬要求：纸色底、墨黑文字、衬线字体、窄栏排版、正文首行缩进两格、标题下双细线。目标是一份真的报纸，不是信息流卡片。
