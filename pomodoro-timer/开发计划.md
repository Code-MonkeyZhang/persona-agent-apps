# 番茄时钟 — 开发计划

## 总览

| 项 | 说明 |
|---|---|
| 目录 | `agent-apps/pomodoro-timer/` |
| Python 包名 | `pomodoro_timer` |
| SOURCE 常量 | `"pomodoro-timer"` |
| 技术栈 | Python + uv / React + Vite + Tailwind v4 / SQLite (stdlib) |
| 主题色 | `#ff4b4b` |
| 参照模板 | `rock-paper-scissors`（骨架）+ `health-manager`（DB 迁移） |

## 工具清单（4 个）

| 工具 | 参数 | prompt 文件 |
|---|---|---|
| `start` | `intent?`, `duration_min?` + 注入参数 | `prompts/start.txt` |
| `stop` | 注入参数 | `prompts/stop.txt` |
| `query_stats` | 注入参数 | `prompts/query_stats.txt` |
| `get_timer_state` | 注入参数 | `prompts/get_timer_state.txt` |

## 通知清单（3 个，行为模式切换信号）

| 通知 | 触发源 | 路由 | 模板文件 |
|---|---|---|---|
| 专注开始（守护模式开启） | WS `start` **或** Agent 调 `start` 工具 | 启动 focus 的 session | `notify_start.txt` |
| 专注结束（守护模式解除） | asyncio 到期 **或** WS `stop` **或** Agent 调 `stop` | 启动 focus 的 session | `notify_end.txt` |
| 休息结束 | asyncio Task 到期 | 启动 focus cycle 的 session | `notify_break_end.txt` |

Agent 自己调 start / stop 工具也触发通知（Agent 需要知道自己进入了/退出了守护模式）。

## Phase 2：前端重构

从原来的单页面改为 Tab 导航 + 两态布局 + 日历历史。

### 删除的组件

| 文件 | 原因 |
|---|---|
| `components/SettingsModal.tsx` | 设置内联到主面板 |
| `components/TodaySummary.tsx` | 不再显示今日汇总 |
| `components/IntentInput.tsx` | 意图输入内联到 Timer.tsx |
| `components/PhaseLabel.tsx` | 被 RoundDisplay 替代 |
| `components/HistoryList.tsx` | 被 HistoryView 替代 |

### 新增的组件

| 文件 | 内容 |
|---|---|
| `components/TimeCircle.tsx` | 可点击 ▲▼ 调时间的圆（idle 态）。中间数字可点击直接键盘输入 |
| `components/TaskStatus.tsx` | 计时态的任务状态文字 |
| `components/RoundDisplay.tsx` | idle 态 `[<] 4 [>]`（左右箭头调轮数，只显示数字）；running 态 `2 / 4`（只读） |
| `components/Calendar.tsx` | 月历网格。有记录的日子画 SVG 圆环（满环）。支持月份切换 |
| `components/DayDetail.tsx` | 选中日的专注列表。每条：时间、意图（空则"工作"）、时长。底部显示总时长 |
| `components/HistoryView.tsx` | 历史 tab 容器，组合 Calendar + DayDetail |

### 修改的组件

| 文件 | 变更 |
|---|---|
| `Timer.tsx` | 顶部 tab 栏（专注 / 历史）；idle 渲染设置态；running 渲染计时态；history 渲染 HistoryView |
| `Countdown.tsx` | strokeWidth 6 → 10 |
| `ControlButtons.tsx` | 保持不变 |
| `useTimerState.ts` | 加 `monthSessions` 状态 + `sendGetMonth`；处理 `month_data` WS 消息 |
| `types.ts` | TimerSettings：3 字段 |
| `constants.ts` | `totalSeconds`：break 阶段用 `break_min`；长休息 = `break_min * 3` |

### 布局对照

**专注 Tab - 设置态（idle）**：Tab 栏 → RoundDisplay（`[<] 4 [>]`）→ 两个 TimeCircle → 意图输入 → 开始按钮

**专注 Tab - 计时态（running）**：Tab 栏 → RoundDisplay（`2 / 4` 只读）→ Countdown（10px 圆环）→ TaskStatus → ControlButtons

**历史 Tab**：Tab 栏 → Calendar（月历 + SVG 圆环标记）→ DayDetail（选中日详情）
