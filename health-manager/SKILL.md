# Health Manager Skill

## 功能概述

Health Manager 是一款用于个人医疗数据管理与收集的 Skill。它通过收集个人医疗数据，方便用户在有医疗需求时，参考其中的数据进行回答。

它的主要核心功能如下：

1. **收集与管理**
   作为个人健康档案的管理中心，负责个人医疗数据的收集与集中管理。
2. **数据导入**
   支持通过 OCR 的方式导入病例数据。

## 主要操作

#### (a) 数据导入

当用户需要导入病例数据时，请按照（`health-profile/scripts/ocr/OCR流程指南.md`）进行操作

#### (b) 数据查询和导入

当用户想要获取最近的健康数据时，请使用 `health-profile/scripts/data-manager/csv_manager.py` 脚本来获取和导入 CSV 文件里的数据。详细使用说明请参考 `health-profile/scripts/data-manager/README.md`。

### 2. 医疗建议

当用户需要医疗建议时，请结合用户的医疗资料 `health-profile/refined_data`，并结合你的医学知识和用药情况进行分析，给出具体数据。
