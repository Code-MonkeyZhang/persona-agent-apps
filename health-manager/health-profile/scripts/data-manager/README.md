# CSV 健康数据管理工具指南

`csv_manager.py` 是一个用于管理 CSV 格式健康数据的命令行工具。它支持数据的查看、搜索、添加（带验证）和统计。

## 功能特性

- **数据查看**: 浏览各个科目的最新数据。
- **全库搜索**: 跨所有 CSV 文件搜索关键词（如“蛋白”、“肌酐”）。
- **安全录入**: 添加数据时自动校验数值范围（防止误录入离谱值）和定性值格式。
- **交互式**: 简单的命令行菜单，无需记忆复杂参数。

## 文件位置

- **脚本**: `health-profile/scripts/data-manager/csv_manager.py`
- **数据源**: `health-profile/refine_data/health_data/csv_output/{分类子文件夹}/*.csv`
  - 子文件夹包括: 血液常规、尿液检查、生化检查、免疫检查、内分泌检查、影像检查、其他检查、字典数据
- **验证规则**: `health-profile/scripts/data-manager/validation_rules.yaml`

## 快速开始

在终端中运行脚本：

```bash
python health-profile/scripts/data-manager/csv_manager.py
```

## 命令说明

进入交互界面后，可以使用以下命令：

| 命令         | 说明                                                   | 示例       |
| :----------- | :----------------------------------------------------- | :--------- |
| `l`          | **List**: 列出所有可用的数据科目（如：血常规、肾功能） | `l`        |
| `v [科目]`   | **View**: 查看指定科目的最近 10 条数据                 | `v 肾功能` |
| `a [科目]`   | **Add**: 向指定科目添加新数据（进入问答模式）          | `a 肾功能` |
| `s [关键词]` | **Search**: 搜索所有包含该关键词的记录                 | `s 蛋白`   |
| `t`          | **Total**: 显示每个科目的数据条数统计                  | `t`        |
| `q`          | **Quit**: 退出工具                                     | `q`        |

## 添加数据流程示例

假设你要添加一条“血肌酐”数据：

1.  输入 `a 肾功能`。
2.  脚本会依次提示输入字段：
    - **日期**: 直接回车默认使用今天。
    - **项目名称**: 输入 `血肌酐`。
    - **数值结果**: 输入 `88`。
    - **单位**: 输入 `umol/L`。
    - ...其他非必填项可直接回车跳过。
3.  脚本会自动检查 `88` 是否在合理范围内（根据 `validation_rules.yaml`）。
4.  验证通过后，数据自动写入 `exam_肾功能.csv`。
