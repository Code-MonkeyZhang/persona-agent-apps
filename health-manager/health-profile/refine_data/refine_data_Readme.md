# Health Profile refine_data 数据体系介绍

## 概述

`refine_data` 是 Health Profile 的核心数据存储区域，用于结构化管理所有健康相关数据。该数据体系采用**数据分类存储**的设计理念，将不同类型的健康数据分别存储在最适合的格式中。

### 设计理念

- **定性数据 → Markdown**: 用于记录医疗事件、决策、主观感受等叙述性内容
- **定量数据 → CSV**: 用于记录医院化验单的详细数值
- **高频数据 → CSV**: 用于记录日常自测的体重、血压等指标

**说明**：

- CSV 数据管理工具已移至项目根目录的 `scripts/data/csv_manager.py`
- 请从项目根目录运行数据管理工具

## 1. Health Journal (health_journal.md)

### 用途

记录**定性的**医疗事件、诊断变更、治疗方案调整和主观感受（非数值类数据），同时维护当前用药方案和历史处方记录。

### 内容结构

#### 个人基本信息

- 姓名、身高、血型、过敏史等静态信息

#### 既往病史摘要

- 慢性疾病、重大病史、手术史等

#### 病例记录（按时间倒序）

- 每次就诊的诊断、化验趋势、治疗方案、医嘱/状态

### 录入原则

1. **去人名化**: 仅记录医院和科室，**不记录医生姓名**
2. **定性描述**: 不写具体数值（如肌酐 110），只描述**趋势**（如"↑ 较上次升高"、"≈ 病情平稳"）。数值请录入数据库
3. **决策导向**: 重点记录**诊断变更**和**方案调整**（换药/增减量）
4. **用药更新**: 处方变更时，优先更新"当前用药方案"表格
5. **时间倒序**: 新的病例记录在最上面

### 填写模板

```markdown
### YYYY-MM-DD (日期) [医院/地点]

- **临床诊断**: [如有更新]
- **化验趋势**: [描述核心指标变化，如：肌酐，蛋白尿]
- **治疗方案**: [描述药物调整，如：新增 xx 药]
- **医嘱/状态**: [医生给出的建议或身体主观感受]
```

### 示例

```markdown
### 2026-02-06 广西医科大学第一附属医院

- **临床诊断**: IgA肾病，高脂血症，高血压，慢性肾脏病3期（失代偿期）
- **化验趋势**: 2025年12月外院尿蛋白1+，ACR 977mg/g，血肌酐110 μmol/L
- **治疗方案调整**:
  - 厄贝沙坦片 0.15g/日（每日一次）
  - 肾炎康复片 0.48g/日（每日三次）
- **医嘱/状态**: 继续规范治疗，定期复查
```

## 2. exam\_\*.csv (health_data/csv_output/)

### 用途

以 CSV 文件形式记录**医院出具**的详细化验单数据。每条记录对应"某日期的一个指标结果"。

### 设计原则

1. **一条记录一个指标**: 每个 CSV 文件中每一行存储一个化验指标
2. **数值与定性分离**: 使用 `value_num` 存储数值，`value_text` 存储定性结果（如"阴性"、"1+"）
3. **标准化单位**:
   - 百分比/比例默认用 `fraction (0-1)`，原始 % 需除以 100
   - 比值（如 A/G、AST/ALT）用 `ratio`
   - 若指标惯常以 % 表示且范围明显 >1（如凝血酶原活动度），可保留 %
4. **标本分类**: 支持 `血液`、`尿液` 等标本类型
5. **科目分类**: 25 个科目（肾功能、血常规、肝功能、血脂、电解质、尿液分析等）

### 使用 CSV 数据管理工具

**注意**：csv_manager.py 已移至项目根目录的 `scripts/data/csv_manager.py`

#### 运行方法

**方法 1: 使用 uv 直接运行（推荐）**

```bash
# 从项目根目录运行
uv run python3 scripts/data/csv_manager.py
```

**方法 2: 激活虚拟环境后运行**

```bash
# 激活虚拟环境
source .venv/bin/activate  # macOS/Linux

# 运行工具
python3 scripts/data/csv_manager.py
```

**方法 3: 进入数据目录运行（不推荐）**

```bash
cd health-profile/refine_data/health_data
python3 ../../scripts/data/csv_manager.py
```

#### 命令说明

- `l` - 列出所有科目
- `v [科目名]` - 查看数据（如: `v 尿蛋白定量`）
- `a` - 添加尿蛋白数据
- `s [关键词]` - 搜索（如: `s 白蛋白`）
- `t` - 统计信息
- `q` - 退出

## 3. daily_metrics.csv (health_data/daily_metrics.csv)

### 用途

记录**居家自测**的高频数据，用于长期健康趋势跟踪。

### 字段定义

| 字段         | 说明                         | 格式/单位  |
| ------------ | ---------------------------- | ---------- |
| 日期         | 测量日期                     | YYYY-MM-DD |
| 体重         | 晨起空腹体重                 | kg         |
| 收缩压(高压) | 血压收缩压                   | mmHg       |
| 舒张压(低压) | 血压舒张压                   | mmHg       |
| 备注         | 补充说明（如心率、测量方式） | 自由文本   |

### 录入原则

1. **晨起空腹**: 体重应在早晨起床后、空腹时测量
2. **固定时间**: 血压建议在固定时间段测量（如早晨）
3. **记录环境**: 备注中可记录测量条件（如"居家自测"、"门诊查体"、"心率76"）
4. **时间顺序**: 新数据追加到文件末尾

### 示例

```csv
日期,体重,收缩压(高压),舒张压(低压),备注
2025-08-08,,115,76,门诊查体
2025-10-29,,126,78,门诊查体
2026-01-08,,127,67,居家自测(心率76)
2026-01-19,82.9,126,70,
```

## 数据流转关系

```
原始病历/化验单
    ↓
rawdata2markdown/（OCR 校对后的 Markdown）
    ↓
人工提取关键数值
    ├─→ exam_data_summary.md（中间记录）
    │
    └─→ csv_output/exam_*.csv（CSV 文件）
```

日常自测数据直接录入 `daily_metrics.csv`。
